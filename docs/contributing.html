Contributing

TalentFlow is open source under the AGPL-3.0 License. We welcome contributions — please start by reading the Code of Conduct.

Setting up for development

npm install
npm run setup
npm run db:seed
npm run dev

Tests

npm test                     # server unit + API integration tests (node:test)

Run the client build to verify the front-end compiles:

cd client && npx vite build

Feature roadmap

See the Feature Matrix for what's shipped, in progress, and on the roadmap.

Documentation

This site is static HTML under docs/, served directly by GitHub Pages — no build step. Edit the pages and commit; Pages picks them up automatically.

Notes

  • The database file is server/data/talentflow.db by default (gitignored); use DB_PATH to relocate. Delete it and re-run npm run db:seed to reset.
  • The dev JWT secret is local-dev-secret-change-me — set JWT_SECRET before exposing anything publicly.
  • WAL mode is on; three -wal/-shm files accompany the DB file — normal.
