API Reference

All routes (except POST /api/auth/login, /api/health, and the /api/public/* portal routes) require Authorization: Bearer <token>.

Recruiter routes

Method & pathPurpose
POST /api/auth/loginGet a JWT (demo@acmetalent.com / password)
GET|POST /api/candidatesList / create candidates
PUT|DELETE /api/candidates/:idUpdate / delete a candidate
GET|POST /api/jobsList / create jobs
PUT|DELETE /api/jobs/:idUpdate / delete a job
GET /api/jobs/:id/matchesRanked candidates for one job (with score breakdowns)
GET /api/matches/allBest candidates per job
GET /api/search?q=Global search across candidates, jobs, and applications
GET|POST /api/screening/questionsScreening-question library
PUT|DELETE /api/screening/questions/:idUpdate / delete a question
GET|PUT /api/jobs/:id/screeningPer-job screening config
GET|POST /api/applicationsList / create applications
PATCH /api/applications/:id/statusUpdate application status / notes
PUT /api/company/brandSet company brand color (admin only)
PUT /api/company/settingsUpdate company profile — name / brand / nav / accent colors (admin only)
PUT /api/company/logoUpload / replace the company logo (admin only)
DELETE /api/company/logoRemove the company logo (admin only)
GET /api/company/lookupSearch public companies by name (admin only)
POST /api/company/adoptAdopt a company's logo + brand color + title (admin only, all-or-nothing)
GET /api/audit?limit=Company-scoped activity log

Public portal routes (no auth)

Method & pathPurpose
GET /api/public/jobsOpen roles (internal fields stripped, includes screening questions)
GET /api/public/companyPublic company brand (logo / brand color / heading)
GET /api/company/logoPublic company logo image
GET /api/public/jobs/:idSingle open role
GET /api/public/questionnaireEEO / self-identification questions
POST /api/public/resume/parseUpload a resume, get auto-filled fields
POST /api/public/applicationsApply (multipart) — requires consent=true
GET /api/public/applications/:tokenApplication status by private tracking link
POST /api/public/applications/lookupList applications for an email address
GET /api/public/privacyPrivacy notice and current policy version
POST /api/public/exportData subject access request (returns erasure_token)
POST /api/public/erasureRight-to-be-forgotten — delete data for an email (403 on wrong token)

Visibility guarantees

  • Match scores are never exposed to candidates — the portal shows stage status only.
  • Screening answers are returned to recruiters with labelled questions; EEO answers are stored server-side (compliance) but never returned by recruiter or portal routes.
