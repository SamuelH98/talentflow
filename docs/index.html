TalentFlow — local-first hiring done right

A LinkedIn Recruiter-style ATS that scores and ranks the best candidates for each role automatically — zero-config, no cloud account, no external AI API, fully offline-capable.

Getting Started View on GitHub
🎯

Transparent candidate ranking

Every candidate is scored against every job with a visible breakdown — skills, experience fit, and years — no hidden black box.

📊

Projects pipeline

A 5-stage kanban (candidates → reached out → interviewing → hired / rejected) that mirrors LinkedIn Recruiter.

🧾

Public candidate portal

A shareable, no-login careers page: one-click apply, resume auto-fill, EEO self-ID, and private status tracking links.

🔒

Privacy & consent built in

Explicit consent, right-to-erasure (DSAR), a company-scoped audit log, and everything stays on your machine.

🏛️

Explainable AI, on-prem

Scoring is fully local and offline-capable. No cloud account, no database server, no external AI API.

⚡

Zero-config startup

One SQLite file. npm run dev and you're hiring — runs in under a minute.
