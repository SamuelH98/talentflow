Introduction

A locally hosted, Workday-style hiring tool that stores your candidate pool and jobs, then scores and ranks the best candidates for each role automatically — with no database server, no cloud account, and no external AI API.

The recruiter app mirrors LinkedIn Recruiter: a top bar with your company brand, an icon rail for navigation, a candidate search with a slide-in profile drawer, a My Jobs view, and a Projects kanban pipeline.

Highlights

  • Candidate & job management — add, edit, archive, delete candidates and jobs
  • Automatic candidate ranking — every candidate scored against every job
  • Transparent scoring — skill / experience / years breakdown behind every match
  • Projects pipeline — matched → in review → interview → hired / rejected
  • Public candidate portal — browse, apply, resume auto-fill, EEO, status tracking
  • Screening questions — reusable bank + per-job configuration
  • Consent + privacy — explicit consent, export, right-to-erasure (DSAR)
  • Dark mode — neutral gray, follows the OS with a manual toggle
  • Multi-company — data scoped per company
  • Locally hosted — everything on your machine, fully offline-capable

Quick start

Requires Node.js ≥ 20 (tested on 24).

npm install             # root (concurrently)
npm run setup           # installs server + client deps
npm run db:seed         # creates the SQLite DB with sample data
npm run dev             # starts API (:4000) + web app (:5173)

Open http://localhost:5173 and sign in with:

  • Email: demo@acmetalent.com
  • Password: password

Candidate portal (no login needed)

http://localhost:5173/#/portal — browse open jobs, apply in under a minute, and track applications. After applying you get a private tracking link (#/portal/status/<token>) you can keep or share. Upload a .pdf, .docx, or .txt resume and the portal auto-fills your details locally (best-effort).

Docker

docker compose up --build

Brings up the whole app on http://localhost:4000. On first run set SEED_ON_BOOT=1 to load demo data and a login.

# optional demo data on first boot
SEED_ON_BOOT=1 JWT_SECRET=$(openssl rand -hex 32) docker compose up --build

Data and uploaded resumes live in the named talentflow-data volume — delete the volume to reset.
